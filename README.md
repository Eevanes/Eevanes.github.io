# Eevanes.github.io

Personal homepage for [Eevanes](https://github.com/Eevanes), built as a lightweight static site and hosted with GitHub Pages.

## Local preview

Serve the directory with any static file server, then open `index.html` through that server.

## Personalization

Project rows currently lead to the public repositories list. The email and LinkedIn controls intentionally show a local notice until real public contact links are provided.
